## ⚙️ Post-Deployment Configuration: Elastic Fleet Server

Once Terraform has finished creating the infrastructure and Kibana is accessible, it is necessary to initialize the Fleet Server. This component acts as the centralized "control panel" that allows us to install agents on other machines and monitor the database (e.g., AWS RDS).

### 1. AWS Prerequisites
Ensure that the EC2 instance's Security Group allows incoming traffic for the Fleet Server.
* **Port:** 8220
* **Protocol:** TCP
* **Source:** 0.0.0.0/0 (or restricted to your public IP / VPC for security).

### 2. Generate the Token in Kibana
1. Access Kibana (`http://<YOUR_EC2_IP>:5601`) with the 'elastic' user and its password.
2. Navigate to **Management > Fleet** in the main menu.
3. Click on **Add Fleet Server**.
4. In step 1, configure the host using HTTPS and port 8220: `https://<YOUR_EC2_IP>:8220`.
5. Click the blue **Generate Fleet Server policy** button.
6. In the code box that appears, copy the **service token** (the long text that appears after `--fleet-server-service-token=`).

### 3. Installation on the EC2 Instance
Connect via SSH to the EC2 instance generated by Terraform and run the following commands in order.

**Note:** We use `sudo` for the download to avoid permission issues with the `ec2-user`. Additionally, the `--insecure` flag during installation is mandatory in this environment when using self-signed certificates.

```bash
# 1. Ensure you are in the user's home directory
cd ~

# 2. Download the agent binaries
sudo curl -L -O https://artifacts.elastic.co/downloads/beats/elastic-agent/elastic-agent-8.12.0-linux-x86_64.tar.gz

# 3. Extract the file
sudo tar xzvf elastic-agent-8.12.0-linux-x86_64.tar.gz

# 4. Enter the directory
cd elastic-agent-8.12.0-linux-x86_64

# 5. Install and initialize the Fleet Server
# IMPORTANT: Replace <YOUR_TOKEN_HERE> with the token copied in step 2 from Kibana.
sudo ./elastic-agent install \
  --fleet-server-es=http://localhost:9200 \
  --fleet-server-service-token=<YOUR_TOKEN_HERE> \
  --fleet-server-policy=fleet-server-policy \
  --fleet-server-port=8220 \
  --insecure
